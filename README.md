 # Sala de aula

 este projeto é um recurso educacional para que os alunos aprendar sobre programação de sistemas através da elaboração de um *software* .

 o projeto é um sitema de gestão de sala de aula, em que será possível:

 1. Adicionar alunos;
 2. Remover alunos;
 3. Atribuir nota a alunos;
 4. Conferir situação do aluno;
 5. Imprimir relatório de alunos, com notas;
